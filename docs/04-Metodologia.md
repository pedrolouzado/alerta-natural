
# Metodologia

<span style="color:red">Pré-requisitos: <a href="03-Product-design.md"> Product design</a></span>

A equipe está utilizando o Visual Studio Code para o desenvolvimento da aplicação, o GitHub para versionamento do código e armazenamento da documentação, Miro para criação  de Personas, Canvas para edição de personas, e o Figma para a criação do protótipo da interface. Essas ferramentas contribuem para a organização e o desenvolvimento do projeto.

## Controle de versão


A ferramenta de controle de versão adotada no projeto foi o [Git](https://git-scm.com/), sendo que o [GitHub](https://github.com) foi utilizado para hospedagem do repositório.

O projeto segue a seguinte convenção para o nome de branches:

- `dev`: versão de desenvolvimento do software

Quanto à gerência de issues, o projeto adota a seguinte convenção para etiquetas:

- `documentation`: melhorias ou acréscimos à documentação

Discuta como a configuração do projeto foi feita na ferramenta de versionamento escolhida. Exponha como a gestão de tags, merges, commits e branches é realizada. Discuta também como a gestão de issues foi feita.

## Planejamento do projeto

###  Divisão de papéis

A nossa equipe adotou uma abordagem colaborativa, sem a definição fixa de papéis, permitindo que todos os integrantes participassem das etapas de desenvolvimento, documentação e design. Foram considerados conceitos do framework Scrum, com divisão dinâmica das tarefas conforme a necessidade do projeto. O acompanhamento das atividades foi realizado por meio do GitHub, contribuindo para a organização e o trabalho em equipe.


## Ferramentas

Os artefatos do projeto foram desenvolvidos com o auxílio de diferentes plataformas, conforme apresentado na tabela a seguir:

Ambiente                | Plataforma            | Finalidade
------------------------|----------------------|--------------------------------------------
Criação de personas     | Miro                 | Elaboração das personas e organização de ideias
Criação de personas     | Canvas               | Estruturação das informações das personas
Desenvolvimento         | Visual Studio Code   | Edição do código da aplicação
Repositório de código   | GitHub               | Versionamento do código e armazenamento da documentação
Projeto de interface    | Figma                | Criação do protótipo da aplicação
